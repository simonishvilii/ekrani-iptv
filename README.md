# Ekrani IPTV — IPTV პლეერი LG webOS და Android TV ტელევიზორებისთვის

საკუთარი IPTV აპი LG webOS 6 ტელევიზორისთვის (შემოწმებულია OLED55B1PVA-ის პარამეტრებზე, webOS 6.6, 1920×1080) და Android TV / Google TV ტელევიზორებისთვის (Xiaomi Mi TV, TCL და სხვ., Android 5+).
ფუნქციებით Televizo-ს მსგავსია, მაგრამ კოდი, დიზაინი და აიქონი სრულიად ახალია.
APK-ს კოდი გამოყენებული არ არის.

**ვერსია 1.3.24.** პაკეტი იქმნება `npm run build`-ით: `dist/com.ekrani.iptv_1.3.24_all.ipk` (dist/ GitHub-ზე არ იტვირთება).

**Android TV:** მზა APK — ტელევიზორის Downloader-ში აკრიფეთ **`is.gd/ekrani`** — [apk/ekrani-iptv.apk](https://raw.githubusercontent.com/simonishvilii/ekrani-iptv/main/apk/ekrani-iptv.apk) (იხ. [1ა](#1ა-android-tv--google-tv-ზე-დაყენება)).

აპი განახლებებს თავად ამოწმებს ამ რეპოზიტორიიდან (`ota/`) — იხ. [განახლებები](#განახლებები).

## 1. ტელევიზორზე დაყენება (webOS Dev Manager)

1. ტელევიზორზე გახსენით **Developer Mode** აპი.
   - **Dev Mode Status** უნდა იყოს **ON**.
   - ჩართეთ **Key Server** და ჩაინიშნეთ ეკრანზე ნაჩვენები **IP მისამართი** და **Passphrase**.
2. კომპიუტერი და ტელევიზორი ერთ ქსელში (Wi-Fi/როუტერში) უნდა იყოს.
3. გახსენით **webOS Dev Manager** და დაამატეთ ტელევიზორი (**Add Device**), თუ ჯერ არ გაქვთ დამატებული:
   - Host: ტელევიზორის IP
   - Passphrase: Developer Mode აპში ნაჩვენები კოდი
4. აირჩიეთ ტელევიზორი, დააჭირეთ **Install** და მიუთითეთ ფაილი:
   `dist\com.ekrani.iptv_1.3.24_all.ipk`

   ახალი ვერსია ძველს ზემოდან ეყენება, წაშლა საჭირო არ არის.
5. აპი გამოჩნდება ტელევიზორის აპების სიაში, სახელით **Ekrani IPTV**.

> ⚠️ **Developer Mode-ს ვადა აქვს.** დარჩენილი დრო ჩანს Developer Mode აპში.
> თუ ვადა ამოიწურა, დეველოპერული აპები ტელევიზორიდან იშლება.
> დროდადრო დააჭირეთ **Extend**-ს Developer Mode აპში, ან გამოიყენეთ webOS Dev Manager-ის ავტომატური გაგრძელება.
> თუ აპი მაინც წაიშალა, უბრალოდ ხელახლა დააინსტალირეთ იგივე .ipk. ფლეილისტები ხელახლა დასამატებელი იქნება.

## 1ა. Android TV / Google TV-ზე დაყენება

1. ტელევიზორზე Google Play-დან დააყენეთ აპი **Downloader** (AFTVnews).
2. ნება დართეთ უცნობი წყაროებიდან დაყენებას: **Settings → Apps → Security / Special app access → Install unknown apps → Downloader → ON** (Xiaomi/TCL-ზე მენიუს სახელები ცოტა განსხვავდება).
3. Downloader-ში ჩაწერეთ მოკლე ბმული **`is.gd/ekrani`**
   (სრული ბმული: `https://raw.githubusercontent.com/simonishvilii/ekrani-iptv/main/apk/ekrani-iptv.apk`).
   ჩამოტვირთვის შემდეგ დააჭირეთ **Install**.
4. აპი გამოჩნდება აპების სიაში სახელით **Ekrani IPTV**.

- ფლეილისტის დამატება და ტელეფონიდან შეყვანა (QR) ისევე მუშაობს, როგორც webOS-ზე.
- **განახლებები:** აპი თავად ამოწმებს ახალ APK-ს (`apk/android.json`) და ახალ ვერსიას გთავაზობთ; **კი** ჩამოტვირთავს და Android-ის დაყენების ფანჯარას გახსნის. პირველად Android-მა შეიძლება „უცნობი წყაროების“ ნებართვა Ekrani IPTV-სთვისაც მოითხოვოს. JS/CSS-ის მცირე განახლებები (`ota/`) ისევე მოდის, როგორც webOS-ზე.
- ვიდეოს უკრავს ExoPlayer (Media3): HLS, MPEG-TS, MP4, DASH. აუდიო ბილიკები და სუბტიტრები იცვლება ისევე, როგორც webOS-ზე.

## 2. პირველი გაშვება — ფლეილისტის დამატება

პირველ გაშვებაზე აპი ფლეილისტის დამატებას ორი გზით გთავაზობთ: ეკრანზე ჩანს QR კოდი ტელეფონისთვის (იხ. ქვემოთ „ტელეფონიდან შეყვანა“) და ღილაკი **ტელევიზორზე შეყვანა**. მოგვიანებით ეს შესაძლებელია **პარამეტრები → + ფლეილისტის დამატება**-დან.

| ტიპი | რა შეიყვანოთ |
|---|---|
| **M3U ბმული** | `http://…/playlist.m3u` (ან `.m3u8`, `get.php?…&type=m3u_plus`) |
| **Xtream Codes** | სერვერი (`http://host:port`), მომხმარებელი, პაროლი |
| **EPG (არასავალდებულო)** | XMLTV ბმული (`.xml` ან `.xml.gz`). თუ M3U-ში `url-tvg` წერია, ავტომატურად აიღებს. შეიძლება რამდენიმე ბმული, მძიმით გამოყოფილი. თუ რომელიმე წყაროს დრო ცდება, ბმულის ბოლოს მიუწერეთ წანაცვლება საათებში: `https://…/epg.xml.gz +2`. ერთსა და იმავე არხზე უპირატესობა სიაში პირველ წყაროს აქვს |

- შეგიძლიათ რამდენიმე ფლეილისტის დამატება.
- **ტელეფონიდან შეყვანა:** **პარამეტრები → ტელეფონიდან დამატება (QR).** ეკრანზე გამოჩნდება QR კოდი და 4-ციფრიანი კოდი. დაასკანერეთ ტელეფონით (ტელეფონი და ტელევიზორი ერთ Wi-Fi ქსელში უნდა იყოს), ფორმაში ჩაწერეთ ბმული/მონაცემები და კოდი, დააჭირეთ „გაგზავნას“. ტელევიზორზე გაიხსნება უკვე შევსებული ფორმა — შეამოწმეთ და შეინახეთ.
- ფლეილისტებს შორის გადართვა: **პარამეტრები → ფლეილისტზე OK → გააქტიურება**.

### tv.team

1. **პარამეტრები → + ფლეილისტის დამატება → M3U ბმული.**
2. ჩასვით თქვენი პირადი ბმული tv.team-ის კაბინეტიდან (`https://hls.gd/pl/…/playlist.m3u8`). EPG-ის ველი დატოვეთ ცარიელი.
3. **ტელეგიდი** ავტომატურად ჩაიტვირთება: ბმული ფლეილისტშივეა (`url-tvg`, epg.team).
   - ეს ძალიან დიდი ფაილია (~55 MB, 3800+ არხი). პირველი ჩატვირთვა ტელევიზორზე 1–3 წუთს გრძელდება. ამ დროს არხების ყურება უკვე შეიძლება.
   - აპი მხოლოდ თქვენი ფლეილისტის არხებს ინახავს (დაახლ. ±7 დღე), ამიტომ შემდეგ გაშვებებზე ტელეგიდი მაშინვე ჩანს.
   - განახლება ფონურ რეჟიმში ხდება (**პარამეტრები → ავტოგანახლება**), ძველი ტელეგიდი ბოლომდე ჩანს.
4. **არქივი:** არხებზე, რომლებსაც 🕘 ნიშანი აქვს, 7 დღის არქივია (`tvg-rec`). გასულ გადაცემაზე OK რთავს ჩანაწერს.
   - როცა გადაცემა მთავრდება, შემდეგი ავტომატურად ირთვება, ბოლოს კი — ლაივი.
5. **ფილმები / სერიალები:** ცალკე ჩანართები აპში აღარ არის (1.3.14-დან წაიშალა). 24/7 კინო-არხები („Movies/Кино“, „Cinemas/Кинозалы“) **ლაივ TV**-ის ჯგუფებშია, ფილმები YouTube-იდან კი — სექციაში **YouTube**.

> 🔒 ფლეილისტის ბმული თქვენი პირადი გასაღებია (ტოკენი). არავის გაუზიაროთ.

### YouTube (შენი არხებიდან)

გვერდით მენიუში არის სექცია **YouTube**. მასში ჩანს იმ არხების ვიდეოები, რომლებსაც თავად დაამატებთ აქ: **პარამეტრები → YouTube არხები**.

- **+ არხის დამატება:** ჩაწერეთ არხის ბმული (`https://www.youtube.com/@name`, `/channel/UC…`, `/c/…`, `/user/…`), უბრალოდ `@name` ან ფლეილისტის ბმული (`…list=PL…`). არხების დამატება რამდენიმე შეიძლება.
- სექციაში პირველი კატეგორია არის **„ყველა ვიდეო“**: ყველა არხის ვიდეოები ერთად, ახლები თავში. შემდეგ ყოველ არხს თავისი კატეგორია აქვს. ბოლო 30 დღის ატვირთვებს **„ახალი დამატებული“** ნიშანი აქვს. რჩეული (🔴), „ნახვის გაგრძელება“ და ძებნა აქაც მუშაობს.
- არხზე OK: განახლება, ზემოთ/ქვემოთ გადატანა, წაშლა. **ყველა არხის განახლება** ყველა არხს ახლავე ამოწმებს (თავისით ამოწმებს ჩართვისას და ყოველ 3 საათში).
- **API გასაღების გარეშე** თითო არხიდან ჩანს ბოლო 15 ატვირთვა (YouTube RSS). Shorts არ ჩანს. ერთხელ ნანახი ვიდეოები ინახება, ასე რომ სია დროთა განმავლობაში იზრდება.
- **YouTube Data API v3 გასაღებით** (უფასოა, Google Cloud Console → APIs & Services → YouTube Data API v3 → Credentials → API key) ჩაიტვირთება არხის **ყველა** ვიდეო (მაქს. 2000 არხზე) და მათი ხანგრძლივობა. შემდეგ **მინიმალური ხანგრძლივობით** (ნაგულისხმევად 20 წთ+) მოკლე კლიპები იმალება და მხოლოდ სრული ფილმები რჩება.
- **გასაღების შემოწმება:** შენახვისას აპი გასაღებს ერთი მოთხოვნით ამოწმებს. თუ გასაღები არ მუშაობს, აჩვენებს Google-ის შეცდომას (მაგ. „API key not valid“) და გასაღები არ ინახება. გასაღებში დიდ და პატარა ასოებს მნიშვნელობა აქვს: `AIza…`, არა `Aiza…`.
- **+ ტელეფონიდან ჩაწერა (QR):** ტელეფონზე, იმავე Wi-Fi-ში, იხსნება ფორმა. მასში ჩაწერეთ (ან ჩასვით) API გასაღები და არხები, თითო ხაზზე ერთი. გასაღები მოწმდება და არხები ერთად ემატება.
- თუ API-მ შეცდომა დააბრუნა, არხს უწერია **⚠ შეცდომა** (არხზე OK აჩვენებს მიზეზს), მაგრამ ბოლო 15 ვიდეო მაინც ჩანს RSS-ით.
- **ვიდეოს ხარისხი** (ნაგულისხმევად **საუკეთესო, 4K-მდე**). YouTube-ის ჩაშენებულ პლეერში ხარისხს პირდაპირ ვერ ავირჩევთ: YouTube ხარისხს პლეერის ზომით ირჩევს. ამიტომ აპი პლეერს 4K ზომით აწყობს და ეკრანზე ამცირებს, YouTube კი უმაღლეს ხარისხს აწვდის, რაც ვიდეოს აქვს და ინტერნეტი იტევს. მიმდინარე ხარისხი (მაგ. `1080p`) ჩანს პლეერის ზოლზე, დროის გვერდით. თუ ვიდეო ჭედავს, აირჩიეთ 1080p, 720p ან „YouTube წყვეტს“.
- YouTube პლეერში: **OK** პაუზა/გაგრძელება, **◀ ▶** ±15 წმ, **⏪ ⏩** ±60 წმ, **▲▼** ინფო, **ყვითელი** იმავე წამიდან ტელევიზორის YouTube აპში გახსნა, **BACK** გამოსვლა (პოზიცია ინახება). თუ YouTube ვიდეოს ჩაშენებას უარყოფს, აპი YouTube აპში გახსნას შემოგთავაზებთ.
- არხებს თქვენ ირჩევთ. აპი მხოლოდ აჩვენებს იმას, რაც YouTube-ზე საჯაროდ დევს და ჩაშენების უფლება აქვს.

## 3. პულტის ღილაკები

| ღილაკი | ლაივ ეკრანზე / სიებში | სრულ ეკრანზე |

## 4. ფუნქციები

- **ლაივ TV**
  - ჯგუფები, არხების სია ლოგოებით, ახლა გასული გადაცემა პროგრეს-ზოლით.
  - პრევიუ ფანჯარა და გადაცემების სია.
  - ვირტუალური ჯგუფები: „ყველა არხი“, „რჩეული“, „ბოლოს ნანახი“.
  - **არხების რედაქტორი** (OK ხანგრძლივად): სახელის შეცვლა, სხვა (ან ახალ) ჯგუფში გადატანა, გადაადგილება სიაში ⬆⬇ ღილაკებით, ტელეგიდის აღება სხვა არხიდან (მაგ. „… HD“-სთვის), დამალვა. დამალული არხების დაბრუნება და ყველა ცვლილების გაუქმება — **პარამეტრები → არხები**. ცვლილებები ფლეილისტის განახლების შემდეგაც რჩება.
  - **მიუწვდომელი არხის გამოტოვება:** თუ არხი რამდენიმე ცდის შემდეგ არ ირთვება, აპი შემდეგზე გადადის (გამორთვა — პარამეტრებში).
  - ინფო-ზოლზე ჩანს ნაკადის ხარისხი (SD / 720p / 1080p / 4K).
  - გამოსახულების ზომა და აუდიო ბილიკი თითოეული არხისთვის ცალკე ინახება.
- **ტელეგიდი (EPG)**
  - XMLTV (`.xml` / `.xml.gz`) ან Xtream API.
  - დიდ, ასობით MB-იან EPG-საც ამუშავებს: სერვისი ფაილს ნაწილ-ნაწილ კითხულობს და აპს მხოლოდ ფლეილისტის არხებს გადასცემს.
  - ბადე არხი × დრო. მონაცემები არხების მიხედვით ინახება ქეშში.
  - დროის წანაცვლება: **პარამეტრები → ტელეგიდის დროის წანაცვლება**. რამდენიმე წყაროსთვის — ცალ-ცალკე, ბმულის ბოლოს `+2` / `-1`.
  - რამდენიმე EPG წყარო ერთად: რომელიც არხი ერთ წყაროში არ არის, მეორიდან აიღებს.
  - **შეხსენებები:** მომავალ გადაცემაზე OK (ტელეგიდში, არხის პროგრამაში ან ძებნაში) დააყენებს შეხსენებას 🔔. დაწყებისას აპი გკითხავთ, ჩაირთოს თუ არა. სია და წაშლა — **პარამეტრები → არხები → შეხსენებები**.
- **არქივი (Catch-up)**
  - გასული გადაცემის ყურება, თუ პროვაიდერი მხარს უჭერს. ასეთ არხს 🕘 ნიშანი აქვს.
  - მხარდაჭერილია Xtream timeshift და M3U `catchup`-ის ფორმატები: default, append, shift, flussonic, xc.
  - `tvg-rec` / `timeshift` (მაგ. tv.team): არქივის სიღრმე დღეებში. Flussonic-ის ბმულებს (`mono.m3u8`, `index.m3u8`) აპი თავად ამოიცნობს.
- **ძებნა** — არხებში, YouTube ვიდეოებსა და ტელეგიდის გადაცემებში ერთდროულად. ნაპოვნ გადაცემაზე OK: ეთერშია — ჩართავს, გასულია — არქივიდან, მომავალია — შეხსენება.
- **მშობლის კონტროლი**
  - 4-ციფრიანი PIN.
  - **პარამეტრები → მშობლის კონტროლი → დაბლოკილი ჯგუფები:** ჯგუფები ფოლდერებად ჩანს; OK ჯგუფს ბოქლომს ადებს ან ხსნის.
  - დაბლოკილი ჯგუფის/კატეგორიის გახსნისას აპი PIN-ს მოითხოვს.
- **პარამეტრები**
  - ენა: ქართული / English / Русский.
  - არხზე დადგომა და OK, ბოლო არხის ავტოჩართვა.
  - Xtream ნაკადის ფორმატი: HLS ან MPEG-TS.
  - გამოსახულების ზომა, ფლეილისტის ავტომატური განახლების ინტერვალი.
- **ქსელი**
  - ფლეილისტებსა და EPG-ს, რომლებსაც ბრაუზერი ვერ ჩამოტვირთავს (CORS, HTTPS სერტიფიკატი, gzip), აპის ჩაშენებული სერვისი `com.ekrani.iptv.service` ტელევიზორზე თავად ჩამოტვირთავს.
  - **სწრაფი ჩართვა:** ბოლო არხი ჩაირთვება მაშინვე, ფლეილისტის ჩატვირთვამდე. თუ ტელევიზორის ჩართვის შემდეგ ინტერნეტი ჯერ არ არის, აპი წერს „ველოდები ინტერნეტს…“ და ქსელის გამოჩენისთანავე აგრძელებს (ხელახალ ცდებზე დროს აღარ კარგავს).
  - ჩართვის დრო (სია / ეკრანი / ვიდეო) ჩანს აქ: **პარამეტრები → აპლიკაციის შესახებ**.
  - **მსუბუქი პაკეტი:** `npm run build` აპის JS/CSS-ს კუმშავს (terser), QR ბიბლიოთეკა კი მხოლოდ ტელეფონიდან დამატებისას იტვირთება — ჩართვისას ტელევიზორს ნაკლები აქვს წასაკითხი.

## განახლებები

- აპი ჩართვიდან ~8 წამში და შემდეგ ყოველ 3 საათში ამოწმებს `ota/version.json`-ს ამ რეპოზიტორიში. ახალი ვერსიისას ჩნდება: „ხელმისაწვდომია აპლიკაციის ახალი ვერსია, გსურთ განახლება?“ — **კი** ჩამოტვირთავს და აპი თავიდან ჩაირთვება.
- ხელით შემოწმება: **პარამეტრები → აპლიკაციის შესახებ** (ვერსიის სტრიქონი). განახლებულ აპს ვერსიის გვერდით აწერია „(განახლებული)“.
- განახლება ცვლის აპის JS-ს და CSS-ს. თუ ახალ ვერსიაში შეიცვალა ის, რასაც განახლება ვერ ცვლის (სერვისი, `index.html`, `js/boot.js`, შრიფტები, აიქონები, `appinfo.json`), აპი იტყობინება, რომ ეს ვერსია კომპიუტერიდან უნდა დაყენდეს.
- თუ განახლებული ვერსია ზედიზედ ორჯერ ვერ ჩაირთო, აპი თავად უბრუნდება დაყენებულ ვერსიას.
- Developer Mode-ის ვადას განახლება არ აგრძელებს.
- **Android:** ჯერ ამოწმებს ახალ APK-ს (`apk/android.json`), შემდეგ JS/CSS განახლებას. თუ შეიცვალა ის, რასაც OTA ვერ ცვლის, ის ახალ APK-ს მოჰყვება.

  - თუ კონკრეტული ნაკადი არ ირთვება, სცადეთ **Xtream ნაკადის ფორმატის** შეცვლა (HLS ↔ MPEG-TS).
  - შეცდომის შემთხვევაში აპი სხვა ფორმატს თავად ცდის.
- მოძველებული, არასტანდარტული M3U ფორმატები შეიძლება ნაწილობრივ ამოიცნოს.
- **შეხსენებები მხოლოდ მაშინ მუშაობს, როცა აპი ჩართულია** (ან ფონზეა). დახურულ აპს ტელევიზორს ვერ ჩართავს და შეტყობინებას ვერ აჩვენებს.
- ტელეფონიდან დამატების გვერდი სახლის ქსელში ჩვეულებრივი HTTP-თ მუშაობს (დაცულია 4-ციფრიანი კოდით და წუთში თავისით ითიშება, თუ აპი აღარ ელოდება). საჯარო/უცხო Wi-Fi-ში ნუ გამოიყენებთ.

## 6. დეველოპერისთვის

```
npm install          # ერთხელ
npm run dev          # http://localhost:8123 — ბრაუზერში სატესტო ფლეილისტით
npm run build        # dist/com.ekrani.iptv_<ვერსია>_all.ipk + ota/
```

**ახალი ვერსიის გამოშვება**

1. ვერსია შეცვალეთ ორ ადგილას: `app/appinfo.json` (`version`) და `app/js/app.js` (`VERSION`).
2. `npm run build` — ქმნის .ipk-ს და `ota/`-ს (`app.js`, `app.css`, `version.json`).
3. commit + push `main`-ში, `ota/`-ის ჩათვლით. ტელევიზორები ახალ ვერსიას `ota/version.json`-იდან ნახავენ.

- სატესტო სერვერზე ხელმისაწვდომია:
  - M3U: `http://localhost:8123/test/playlist.m3u`
  - Xtream: სერვერი `localhost:8123`, მომხმარებელი/პაროლი `demo` / `demo`
- ბრაუზერში ფერადი ღილაკები არ არის, Back = **Esc**.

**Android (APK)**

საჭიროა JDK 17, Android SDK (platform 35, build-tools) და Gradle 8.9.

```
npm run build:android -- --debug            # dist/ekrani-iptv-debug.apk (სატესტო)
npm run build:android -- --bump --publish   # ვერსია +1, ხელმოწერილი APK → apk/ekrani-iptv.apk + apk/android.json
```

- ახალი APK საჭიროა მხოლოდ მაშინ, როცა `android/`-ში ან OTA-ს მიღმა ნაწილებში (index.html, boot.js, სერვისი, შრიფტები…) რამე შეიცვალა. დანარჩენს `ota/` აწვდის.
- ხელმოწერის გასაღები (`~/.ekrani/ekrani-release.jks` + `signing.properties`) რეპოზიტორიში **არ** ინახება. შეინახეთ მისი ასლი: სხვა გასაღებით ხელმოწერილი APK ძველს ზემოდან ვერ დაეყენება.
- ვებ-აპი Android-ზე უცვლელად ეშვება WebView-ში; `android/shim/android.js` webOS-ის API-ებს (Luna სერვისი, ვიდეო, პულტის ღილაკები) Kotlin-ის მხარესთან აკავშირებს.

**სტრუქტურა**

- `app/` — ვებ-აპი: `index.html`, `css/`, `js/` და `js/screens/`.
- `service/` — Node.js სერვისი ქსელისთვის.
- `tools/` — სატესტო სერვერი, build და აიქონის გენერატორი.
- `android/` — Android TV აპი (Kotlin: WebView + ExoPlayer + ქსელი/LAN/განახლებები); `apk/` — გამოქვეყნებული APK.
- `app/local/playlist.m3u8` — პირადი ფლეილისტი მხოლოდ სატესტო build-ებისთვის (GitHub-ზე არ იტვირთება, არც გამოქვეყნებულ APK-ში და `ota/`-ში ხვდება). აპი მას ერთხელ ამატებს, როგორც „tv.team (ფაილი)“; პარამეტრებიდან წაშლის შემდეგ აღარასდროს დაამატებს.
- `app/js/reminders.js` — შეხსენებები; `app/js/lan.js` — ტელეფონიდან დამატება (გვერდს `service/index.js` ემსახურება, პორტები 8890–8899).
